# RMBG Studio — Frontend (Next.js)

Bu dizin, **RMBG Studio** uygulamasının **Next.js (App Router + TypeScript + Tailwind CSS)** ile geliştirilmiş kullanıcı arayüzünü ve çok katmanlı **HTML5 `<canvas>`** kompozisyon motorunu içerir.

Detaylı sistem mimarisi, derin öğrenme modelinin çalışma prensibi ve kurulum adımları için bir üst dizindeki ana **[README.md](../README.md)** dosyasına göz atabilirsiniz.
